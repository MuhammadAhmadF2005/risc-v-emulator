***Hello, this is a RISC-V Emulator project written in C++ with the ultimate goal of running DOOM!***

## Repository Structure
- **[MyRiskVemulator/](file:///c:/Users/HP/Desktop/risc-v/MyRiskVemulator)**: Main C++ RISC-V emulator codebase and CMake project.
- **[learning/](file:///c:/Users/HP/Desktop/risc-v/learning)**: Practice exercises, session files (from https://cass-kul.github.io/), and early processor prototype experiments.

## Project Details
*The sessions in `learning/` are adapted from https://cass-kul.github.io/ with custom exercise implementations.*

*This emulator implements RV32I base instructions in C++ using custom logical handling. The primary goal is to simulate ELF file execution (linkers, loaders, memory mapping) and run DOOM. Follow along and don't forget to star the repository!*
